# Arcade Games

Hub visual para una colección de juegos. Por ahora muestra tres juegos y portadas provisionales.

Abre `index.html` en un navegador para verlo. La interfaz no necesita instalar dependencias ni conectarse a internet.

Los datos de las tarjetas y del diálogo están en `app.js`. Cuando haya un juego listo, se puede añadir su ruta allí y convertir el botón **EXPLORAR** en un enlace de juego.
